Two models for the same task

One attention function 2,528 parameters

Positions 1–5 supply keys and values. Position 6 supplies the only query. Take five raw dot products, weight the values, and send their sum to the word output head.

One head, with no attention softmax, nonlinear activation layer, positional encoding, or normalization.

Two-layer MLP 2,607 parameters

Concatenate the six 16-dimensional embeddings in input order. Map 96 inputs to 11 hidden units, apply ReLU, then map the result to 55 word scores.

Both models use the same final-word cross-entropy over vocabulary logits.

The attention sum is invariant to swapping the two items. The MLP’s first layer has distinct weights for each slot.

How close is the run to the best possible loss?

Cross-entropy is nonnegative. We can construct parameters for this attention model that select the correct item using 1/0 scores. Its output head gives every item a distinct direction on the unit circle. Scaling that head widens the correct logit’s lead, driving CE toward zero.

Constructed head scaleTrain CETest CETest top-1

Zero is the infimum. With finite logits, the true word has probability below one. An observed CE of ε puts the run within ε of the global infimum on that split.

Data and training code

20 fruits × 30 vegetables × 2 orders × 2 requests = 2,400 examples. Train on 480 pairs (1,920 examples), then test on the other 120 pairs (480 examples). Every produce word occurs in training. All examples for the same pair stay in the same split.
