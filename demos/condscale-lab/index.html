A random d × n matrix X · the matrix GD moves in is XXᵢ. Change the size, the distribution, the seed — then change the preprocessing and see how κ changes as the inputs change.

κnz(XXᵢ) = λmax / λmin,nz  —  zero eigenvalues are excluded (they cost nothing; Paradox 1), and their count is shown separately as null directions.   Row normalization = symmetric Jacobi scaling; centring is what changes the angle between a row and the mean.

Pipeline, top-left to bottom-right: raw → centred (subtract the row mean, add δ) → normalized (divide each row by its norm, multiply by c) → both. All four use the same draw. If d > n, XXᵢ has d − n exact zeros — that is why the smallest non-zero eigenvalue is the one that counts.
