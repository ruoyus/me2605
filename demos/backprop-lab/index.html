Above each layer: the update of that layer, its weight matrix, and what the step turns it into. A matrix is written row by row, [a b ; c d] (… = entries that did not fit); a vector component goes in brackets, e2[1]. In ∂L/∂Wl = el(zl−1)T the red e is the error left by the backward pass, and the blue z is the activation carried by the forward pass — the two arrows follow each one to where it is made. 每层上方：该层的更新、该层的权重矩阵，以及这一步把它变成什么。矩阵按行写，[a b ; c d]（… 表示放不下的元素）；向量的分量放方括号里，e2[1]。在 ∂L/∂Wl = el(zl−1)T 里，红色的 e 是反向传播留下的误差，蓝色的 z 是前向传播带过来的激活；两条箭头各自指到它产生的地方。

The output layer is sigmoid + binary cross-entropy, so eL = ∂L/∂hL = p − y. The notes write the same error as e = hL − y for the quadratic loss. 输出层是 sigmoid + 二元交叉熵，所以 eL = ∂L/∂hL = p − y；讲义里对平方损失把同一个误差写成 e = hL − y。
