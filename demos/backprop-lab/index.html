Backpropagation, one phase at a time一步一步看反向传播

A tiny network, one training example, and three phases you can step through: forward to get the prediction, backward to get the gradient of every edge, update to change the weights. Nothing is pre-computed — the numbers on screen are the numbers the code just produced. 一个很小的网络、一个训练样本、三个可以逐步走的阶段：前向算出预测，反向算出每条边的梯度，更新改权重。页面上显示的数是代码刚刚算出来的，没有任何预录。

The one formula to take away. For every layer, the backward pass needs only two things: the error signal coming from the layer above, and the activations of the layer below.
  δ l = (W l+1)T δ l+1 ⊙ φ′(z l)   and   ∂L/∂W l = δ l (a l−1)T 唯一要记住的公式。每一层的反向传播只需要两样东西：从上一层传回来的误差信号，和下面一层的激活值。
  δ l = (W l+1)T δ l+1 ⊙ φ′(z l)   以及   ∂L/∂W l = δ l (a l−1)T

keep it small — the point is that you can check every number by hand刻意保持很小——目的是每个数都能手算核对

2 input features → hidden layer(s) with φ → 1 output with sigmoid → binary cross-entropy on one example. p = σ(z), L = −[y log p + (1−y) log(1−p)]. Every hidden layer also has a bias, and so does the output. 2 个输入特征 → 一到两层带 φ 的隐藏层 → 1 个 sigmoid 输出 → 在单个样本上的二元交叉熵。p = σ(z)，L = −[y log p + (1−y) log(1−p)]。每个隐藏层和输出层都带偏置。

Loss on the whole training set整个训练集的损失

Grey dashed line: the loss of a network that always answers 0.5 (log 2). Every step is one example, so the curve is noisy — that is what stochastic gradient descent looks like. Try setting φ to linear: the curve will stall exactly on that line, because then the network cannot represent XOR at all. 灰色虚线：永远回答 0.5 的网络所对应的损失（log 2）。每步只用一个样本，所以曲线会抖——随机梯度下降本来就是这样。把 φ 换成 linear 试试：曲线会恰好停在这条线上，因为此时网络根本无法表示 XOR。

Everything runs in the browser: no server, no data leaves the page, and it works offline. Parameters are stored in 64-bit floats so that the numbers shown agree with a hand calculation to the last digit. The loss is cross-entropy on one example; the gradient shown on each edge is ∂L/∂w for that single example, which is exactly what stochastic gradient descent uses. 全部在浏览器里运行：没有服务器、数据不出页面、断网可用。参数用 64 位浮点存储，所以显示的数和手算结果能对到最后一位。损失是单样本的交叉熵；每条边上显示的梯度就是该样本的 ∂L/∂w，也正是随机梯度下降实际使用的东西。
