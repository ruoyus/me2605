Build the network, then set how every single layer is initialized — a constant, a 0/1 matrix, Gaussian or uniform — and pick the learning rate. Press Train and look at the error. Nothing on this page tells you which choice is right; finding that out is the experiment. 先搭好网络，然后逐层设置初始化方式——常数、0/1 矩阵、高斯或均匀分布——再选学习率。按下 Train，看误差。这一页不会告诉你哪种选择是对的，把它试出来就是这次实验的目的。

An error of 50% means the network learned nothing at all — that is the chance level for this data set. Judge a configuration only by whether the two curves come down and stay down. 误差 50% 意味着网络什么都没学到——这正是这份数据集的瞎猜水平。判断一组配置好不好，只看两条曲线有没有降下来并稳住。

Decision boundary决策边界

The most recent run, on the two interleaved spirals. A network that has actually learned bends the boundary around the origin. 最近一次训练的结果，数据是两条互相缠绕的螺旋。真正学到的网络，决策边界会绕着原点弯过去。

Each run keeps its curve when you train again (up to five), so you can change one thing and compare directly. The curves show error, not loss: the fraction of misclassified points, which is what you can actually read off an axis. 每次训练都会把曲线留在图上（最多保留五条），这样可以只改一处然后直接比较。图上画的是误差而不是损失：分错点的比例，这是真正能从坐标轴上读出来的量。

400 training and 400 test points, generated in the page from the seed. SGD with momentum, a fixed number of steps and no gradient clipping, so that a scale which is far too large is allowed to blow up; a run whose gradients turn non-finite is marked diverged and stopped. The curves are noisy on purpose — that is what a single run actually looks like. 训练集与测试集各 400 点，由页面按种子实时生成。带动量的 SGD，步数固定，且不做梯度裁剪，因此尺度过大时就真的会炸；梯度出现非有限值的运行会被标记为 diverged 并中止。曲线有抖动是刻意的——单次训练实际就是这样。
