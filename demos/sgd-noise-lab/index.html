Fluctuate or converge?

In class we proved that SGD with a constant stepsize α only reaches a neighborhood of size O(α σ²). Here you train real neural networks on real MNIST digits and find out when that neighborhood appears — and when it disappears. All curves come from actual training in your browser.

What is being trained? Read the experimental protocol.

Data: 10,000 real MNIST digits (the npm mnist package), averaged 2×2 down to 14×14 pixels and standardized with training statistics. 4000 digits for training, 2000 held-out digits for testing. Network: a ReLU MLP x → [Linear → ReLU (→ LayerNorm)] × L → Linear → softmax cross-entropy, He initialization, double precision. Optimizer: plain SGD, w ← w − α ∇f_B(w), mini-batches of B indices sampled with replacement from a seeded stream that is shared by all runs. No momentum, no weight decay, no clipping. Curves: loss and accuracy on fixed subsets of 1000 training and 1000 test digits; the cards report the full sets at the end. Gradient noise: 128 per-sample gradients at the current weights.

The theorem in class is for strongly convex functions; a neural network is not convex. The lab tests whether the theorem's prediction — floor ∝ α σ², and no floor when σ² = 0 — still describes what we see. These are toy experiments on 4000 digits; try other seeds before drawing conclusions.

02 / WHAT THE THEOREM PREDICTS

The confusion zone has size α σ². What if σ² = 0?

Theorem 2 (constant stepsize, strongly convex)

Φt = E‖wt − w*‖² ≤ Φ* + (1 − μα)2t [Φ0 + α²σ² − Φ*]
Φ* = α σ² / (μ (2 + μα)) ≈ α σ² / (2μ)

σ² bounds the variance of the stochastic gradient, E‖∇f_i(w) − ∇F(w)‖² ≤ σ². With a mini-batch of size B it becomes σ²/B.

Three predictions to test

1. Floor ∝ α. A network that cannot fit the data keeps σ²(w) > 0, so a larger α gives a higher, noisier floor (scenario 1).
2. Floor ∝ 1/B. A larger batch reduces the gradient noise σ²/B, so the floor shrinks (scenario 2).
3. No floor under interpolation. If the network is large enough to fit every training digit, then every ∇f_i(w*) = 0, so σ²(w*) = 0 and Φ* = 0: SGD with a constant stepsize converges (scenarios 3 and 6). Overparameterization removes the confusion zone — just like Example 1a with identical data.
Connection to Part II: if the network cannot fit, how could you get below the floor without changing the network or the batch? (Remark 2: let α → 0. That is what a learning-rate schedule does.)
03 / DISCUSS

Questions to answer after running

  1. Scenario 1: read the fluctuation (±) on each card. Does it roughly double when α doubles? What does σ² do during training?
  2. Scenario 3: the wide network uses the same stepsizes. Why does a larger α now give a lower loss, the opposite of scenario 1?
  3. Scenarios 4–6: does LayerNorm remove the floor of the small network? What does it change for the deep network?
  4. Test accuracy is not training loss. Is the run with the lowest training loss always the one with the highest test accuracy?
