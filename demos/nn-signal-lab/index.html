Why initialization decides whether a deep network can train 为什么初始化决定了深层网络能否被训练

A five-slide background, then an interactive lab where you control the initialization scale and watch the signal travel through the layers. 先看五页背景，然后进入交互实验台：自己调节初始化尺度，观察信号在各层之间如何传播。

1 / 5

A fully connected network is a stack of affine maps and activations 全连接网络 = 一串仿射变换 + 激活函数

A standard L-layer fully connected network (FCN, a.k.a. MLP) is 一个标准的 L 层全连接网络（FCN，也叫 MLP）写作

fθ(x) = WL φ( ⋯ φ(W2 φ(W1x + b1) + b2) ⋯ ) + bL

or, with a clean recursion,或者写成更清爽的递推形式：

z0 = x   ·   zl = φ(Wl zl−1 + bl)   ·   fθ(x) = WL zL−1 + bL
  • φ is the activation, applied element-wise; Wl has dimension dl × dl−1; the parameters are θ = {Wl, bl}. φ 是逐元素作用的激活函数；Wl 的维度是 dl × dl−1；参数为 θ = {Wl, bl}。
  • d0 = dx (input dimension) and dL = dy (output dimension). d0 = dx（输入维度），dL = dy（输出维度）。
  • Slide content follows the course book, Optimization for Deep Learning, §2.1. 本页内容对应讲义 Optimization for Deep Learning 第 2.1 节。
2 / 5

Two values per layer: pre-activation and post-activation 每一层有两个量：pre-activation 与 post-activation

Each layer's operation splits into two stages — an affine transformation, then a non-linear activation: 每层的运算分成两步——先做仿射变换，再做非线性激活：

pre-activation:  hl = Wl zl−1 + bl,   l = 1, …, L
post-activation:  zl = φ(hl),   l = 1, …, L−1 The last layer is usually taken without activation: fθ(x) = hL.

This lab's dashboard tracks both of them, layer by layer. That is the whole point: the size of hl tells you what the weights did, and the size of zl tells you what survives into the next layer. 本实验台的看板会同时跟踪这两个量。这正是关键：hl 的大小反映了权重做了什么，zl 的大小则决定了有多少信号能传到下一层。

The same decomposition is what backpropagation uses: it needs the derivative φ′(hl) at the pre-activation. 反向传播用的也是同一套分解——它需要 pre-activation 处的导数 φ′(hl)。

3 / 5

Signal propagation: what happens to the scale as depth grows? 信号传播：层数变深时，信号的大小会怎样？

Depth is a product of matrices: zL = WL WL−1 ⋯ W1 x (for a linear network). If each step multiplies the norm by a number slightly different from 1, the effect compounds exponentially. 深度本质上是一串矩阵相乘：对线性网络，zL = WL WL−1 ⋯ W1 x。只要每一步把范数乘上一个略偏离 1 的因子，累积起来就是指数级的效果。

‖zL‖ ≈ ‖x‖ · cL c < 1 → vanishing  ·  c ≈ 1 → preserved  ·  c > 1 → exploding

We want the "energy" of the output to be comparable to the input — the energy-preserving principle: 我们希望输出的"能量"与输入相当，也就是能量守恒原则：

E‖ WL ⋯ W1 x ‖² / dL  =  ‖x‖² / d0

That is why the lab plots the per-unit RMS (‖·‖² divided by the width) — on that scale the target is a flat horizontal line at the input value, for every depth. 所以实验台画的是单位维度 RMS（‖·‖² 除以宽度）——在这个尺度下，理想情况就是从输入到输出的一条水平线，与深度无关。

4 / 5

The initialization scale is the knob that sets c 初始化尺度就是控制 c 的那个旋钮

Draw the weights i.i.d. from a Gaussian whose variance is scaled by the fan-in, with a tunable gain g: 让权重独立地取自高斯分布，方差按 fan-in 缩放，并留一个可调的增益 g：

Wlij ~ N( 0 , g² / dl−1 ) g = 1 → Bottou–LeCun (var = 1/fan-in)  ·  g = √2 → He / Kaiming (for ReLU)

Both classical recipes are the same formula at a different gain. Set the gain too low and the signal decays to nothing; too high and it blows up. Somewhere in between, the network sits at the critical point where the signal neither vanishes nor explodes. 两个经典方案其实是同一个公式、不同的增益。增益太小信号会衰减到零，太大则会爆炸；而在中间某个位置，网络处于临界点——信号既不消失也不爆炸。

5 / 5

A note on the numbers we report: error, not loss 关于报告什么数字：用 error，而不是 loss

Training minimises a loss (here, binary cross-entropy) because a smooth surrogate is what gradient descent can handle. But the quantity you actually care about is the error — the fraction of misclassified examples. 训练时最小化的是 loss（这里是二元交叉熵），因为梯度下降需要一个光滑的替代目标。但你真正关心的是 error——分类错误的样本比例。

The two are different objects: a local minimum of the training loss is not necessarily a local minimum of the training error. The lab therefore plots training error and test error directly, so you can read the story off the y-axis without translating through a log-loss scale. 两者不是一回事：训练 loss 的局部极小点未必是训练 error 的局部极小点。因此实验台直接画 训练 error 与 测试 error，你可以直接从纵轴读出结论，不必在 log-loss 尺度上做换算。

Task: two interleaved moons, 2 features, 400 training and 400 test samples. A deep network has to carve a curved boundary through them — easy with a healthy signal, impossible when the signal has died. 任务：两条交错的月牙，2 个特征，400 个训练样本、400 个测试样本。深层网络需要切出一条弯曲的边界——信号健康时很容易，信号死掉时则完全做不到。

Two things worth noticing. (1) For φ = linear the prescription var = 1/fan-in (g = 1) is exact, and for ReLU the variance-preserving gain is exactly √2 — that is the He/Kaiming rule. For tanh the variance-preserving gain is larger (≈1.6), because the non-linearity itself removes variance; the classical g = 1 is still the right practical default, and the lab lets you see both. (2) The training panel is deliberately small (≤ 24 layers, ≤ 24 wide, gradient clipping on) so that it finishes in a few seconds — the ordering of the curves is the message, not the absolute numbers. 两点值得注意。（1）当 φ = linear 时，var = 1/fan-in（即 g = 1）是精确的解；当 φ = ReLU 时，保持方差的增益恰为 √2，这正是 He/Kaiming 规则。对 tanh，保持方差的增益更大（约 1.6），因为非线性本身会损失方差；而经典的 g = 1 仍是实用的默认值，实验台让你同时看到这两件事。（2）训练面板刻意做得很小（≤24 层、宽度 ≤24、开启梯度裁剪），以便几秒内跑完——要看的是曲线的相对次序，而不是绝对数值。
