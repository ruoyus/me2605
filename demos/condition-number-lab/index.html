What to check

  • Read κ off the panel, then predict the steps yourself: about (κ/2)·ln(1/ε), with ε measured on the relative gap (F − F*)/(F0 − F*).
  • Areas × 0.01 leaves κ near 4,500; areas × 0.0001 leaves it near 44.
  • A lower κ is not a smaller objective: both scalings solve the same problem.
  • The prediction is an upper bound. A run that is faster is fine; a slower run means the two numbers disagree.
  • For this model the Hessian is constant, so κ at the start is κ all the way; for a nonlinear model it would drift, which is why normalization acts at every layer.
