What is being trained? Read the experimental protocol.

A ReLU MLP learns two noisy interlocking moons: 768 training points and 256 independently sampled held-out points. Input scale multiplies only the second coordinate; labels and latent points stay unchanged. He initialization, trained linear-layer biases, a single output logit, binary cross-entropy and plain SGD. There is no clipping, optimizer momentum or weight decay. γ starts at 1, β at 0. ε = 10⁻⁵. BN updates stored means and unbiased variances with momentum 0.1; its training forward pass uses the biased batch variance. The held-out set is never used to update weights or running statistics.

Placement here means before/after ReLU inside an MLP, not Transformer pre-LN/post-LN residual blocks. These are toy experiments, not a universal ranking of normalization methods. Try several seeds and learning rates. Repeatedly choosing settings on this held-out set makes it a validation set, not an untouched final test set.

03 / TRAINING ≠ INFERENCE?

Which statistics are used at test time?

Same trained BN model, two evaluation rules

Run an experiment to compare the two rules.

The diagnostic uses current test mini-batch statistics, without updating the model. Test batches use your selected batch size. It is not the standard BN evaluation rule; changing batch companions can change predictions.

LN keeps the same computation

For each new sample, recompute its feature mean and variance. Use the same learned γ and β as in training. There are no running statistics and no batch companions to depend on.

This removes BN’s change of statistics rule, not every possible train–test problem. Narrow layers can discard useful information; distribution shift and overfitting remain possible.

Discuss: when the batch is small, is a better training loss enough to predict better inference accuracy? Check both BN evaluation rules before answering.
