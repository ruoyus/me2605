Optimizer Race Lab

One quadratic, three optimizers, the same step budget. The Hessian is block diagonal: six blocks, eight coordinates each, and the blocks are allowed to differ in scale. This is the object Lec 6 uses to explain why Transformers need Adam — change the preset and watch which blocks each method leaves behind.

Problem

With tuning on, each method gets the best constant step size from a small sweep, so the comparison is not an artefact of one bad η. Turn it off to use η = 1/L for SGD and momentum and η = 0.03 for AdamW.

What is being solved. F(w) = ½ w⊤Hw, with H block diagonal and Hb = sb Qb Λb Qb⊤. Block b has its own scale sb; inside a block the eigenvalues run from sb down to sb/κ. The optimum is w = 0, so the loss can reach zero and whatever is left is error. One step size has to serve all six blocks — that is the whole difficulty. AdamW moves each coordinate by roughly η whatever the gradient size, so at a constant η it hops around the optimum instead of settling; the spikes on its curve are that hop, and they are the reason the last lecture section decays η at the end of a run.
