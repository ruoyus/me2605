Keep a deep network at scale: constrain the weights, or standardize the activations? 让深层网络保持在合适的尺度：约束权重，还是标准化激活？

Five slides of background, then a lab that trains the comparison in your browser: one deep network, a baseline and six mechanisms, and an input whose feature scales you control. 先看五页背景，然后进入实验台：同一套深层网络、一个基线加六种机制，输入特征的尺度由你控制，训练就在浏览器里跑。

1 / 5

A scale requirement can be imposed in two places 「尺度要求」可以加在两个地方

A network is a stack of maps. If you want every layer to stay at a controlled size, you can act on the parameters Wl — or on the activations zl that those parameters produce. The two are not the same intervention, and they are not equally effective. 网络是一串映射。想让每一层保持在可控的大小上，你可以对参数 Wl 动手，也可以对参数造出来的激活 zl 动手。这是两种不同的干预，效果也不一样。

Same goal — keep the signal from drifting — reached by two different interventions. This lab measures which one survives a hard input. 同一个目标——不让信号漂走——两种干预方式。这个实验台测量的就是：碰上困难的输入，哪一种能撑住。

2 / 5

Conditioning: identical data, two sets of feature scales 条件数：同一批数据，两套特征尺度

A least-squares fit of house price on two features — floor area and number of rooms. The two columns are in different units, so one is numerically large and one is small. The eigenvalues of XXT separate: (0.0004, 1.856) — κ ≈ 4640. Rescale the two columns and the same fit has (0.4, 18.45) — κ ≈ 46. 用两个特征——面积和房间数——做房价的最小二乘拟合。两列的单位不同，一列数值大、一列小，XXT 的特征值就分开了：(0.0004, 1.856) — κ ≈ 4640。把两列重新缩放，同一个拟合变成 (0.4, 18.45) — κ ≈ 46。

Nothing about the task changed — only the units. The conditioning is a property of how the input is scaled, not of the model. 任务本身没变，变的只是单位。条件数是输入如何被缩放的属性，不是模型的属性。

3 / 5

Centering and rescaling is a preconditioner — and not a universal one 中心化 + 重新缩放是一种预条件——但不是万能的

Subtract the column mean, divide each column by its norm: that is Jacobi preconditioning. It is cheap and it often tightens the eigenvalues a great deal. It is not a theorem: Sun & Ye (2019) give matrices for which the preconditioned system is worse conditioned than the original. 减掉列均值、再把每列除以自己的范数：这就是 Jacobi 预条件。它很便宜，经常能把特征值收紧很多。但它不是定理：Sun & Ye (2019) 给出了预条件之后条件数反而更差的矩阵。

4 / 5

Acting once, on the input, only fixes layer 0 只在输入上做一次，只能修好第 0 层

Standardizing X before the network hands layer 0 a well-scaled input. But layer l does not see X; it sees Zl−1, which the previous layer produced and which moves at every step. 在网络之前把 X 标准化，第 0 层拿到一个尺度良好的输入。但第 l 层看到的不是 X，而是 Zl−1——上一层的输出，每一步都在变。

So the target moves inside the network: standardize Zl itself, at every layer — the rows of the activation matrix, one row per sample. 所以目标要挪到网络内部：在每一层直接标准化 Zl——激活矩阵的每一行，一行一个样本。

5 / 5

The four parameter-side fixes all cost something 四种「权重侧」的修法都要付出代价

Take a toy problem: find w with ‖w‖ ≈ 1. There are four standard ways to force it, and each one damages what the network can represent. 拿一个玩具问题：求 w，要求 ‖w‖ ≈ 1。有四种标准做法，每一种都会损伤网络的表达能力。

The lab below keeps the four parameter-side mechanisms at their best starting point, so that a failure cannot be blamed on the initialization. 下面的实验台让四种权重侧机制都从「已经满足自身约束」的位置出发，这样失败就不能归咎于初始化。

What is fixed固定的

  • ReLU, plain SGD, batch 24, 300 steps, step size η = 0.05, 48 inputs, 1 536 train / 512 test samples.ReLU、纯 SGD、批大小 24、300 步、步长 η = 0.05、48 维输入、训练 1 536 / 测试 512 个样本。
  • Weights start at He: W ~ N(0, 2/fan_in); every layer also carries a zero-initialised bias, learned like the weights.权重起点是 He：W ~ N(0, 2/fan_in)；每层另有一个零初始化的偏置，和权重一起学。
  • Each input feature is multiplied by a fixed log-uniform factor spanning 10⁻² … 10² — identical data, incoherent scales.每个输入特征乘一个固定的对数均匀因子，跨 10⁻² … 10² — 同一份数据，尺度互不相称。
  • The two weight-side mechanisms aim at row norm √2 — the value He initialization already gives, so they start at a point that satisfies their own constraint. Regularizer strength 1.0.两种权重侧机制的目标行范数都是 √2 — 正是 He 初始化已经给的值，所以它们起点就满足自己的约束。正则强度 1.0。
  • The seed is fixed: the same setting and the same mechanism give the same run.随机种子固定：同样的设定、同样的机制，给同样的结果。

A · Scale of what enters the activation, layer by layerA · 进入激活函数之前的尺度，逐层

√mean of the squares of the pre-activation, after that layer's own mechanism has acted, on the test batch. The curve is measured at initialization and then replaced by the running network's measurement as training proceeds. 激活前数值的均方根（在该层自己的机制作用之后），在测试批上测量。曲线先给初始化的测量，训练推进时被当前网络的测量值替换。

B · Test error while trainingB · 训练过程中的测试错误率

Misclassification rate, one curve per run you start. A curve that stops is a run whose gradient stopped being finite — that is a result, not a missing point. 误分类率，每跑一次一条曲线。曲线中断表示这次运行的梯度不再是有限值 — 那是一个结果，不是一个缺失的数据点。
