How the map is made

After training to θ*, draw two Gaussian random directions δ and η of the same shape as θ*, then plot

f(α, β) = L(θ* + α·δ + β·η), α, β ∈ [−r, r]

Filter normalization. Each direction is rescaled neuron by neuron (row by row of each weight matrix Wl) so it has the same norm as the corresponding row of θ*:

δl,i ← δl,i / ‖δl,i‖ · ‖θ*l,i‖

Without it, ReLU and normalization layers make the picture depend on weight scale rather than geometry. Set Direction scaling to “none” to see the distortion. As in the paper, bias and normalization parameters get zero direction by default.

Details. The loss is the full-batch cross-entropy on the chosen set. BatchNorm uses full-batch statistics at every grid point, so its scale invariance shows in the map. Values above 10 are clipped. Each map is one random 2D slice of a space with thousands of dimensions, so change the direction seed before you draw conclusions.

Grid statistics. “Local minima” counts interior grid points lower than all 8 neighbours. “Non-convex” is the share of points whose finite-difference Hessian has λmin < 0 with |λmin/λmax| > 0.1, a rough version of the paper's convexity map.
