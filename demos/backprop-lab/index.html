Backpropagation, one phase at a time一步一步看反向传播

A tiny network, one example, three phases: forward to get the prediction, backward to get the error of every node, update to change the weights. Nothing is pre-computed, and the weights and inputs are round numbers on purpose — every line on this page can be checked by hand. 一个很小的网络、一个样本、三个阶段：前向算出预测，反向算出每个节点的误差，更新改权重。没有任何预录，而且权重和输入刻意用整数分数——本页每一行都能手算核对。

The two formulas this whole demo is about. For every layer, the backward pass needs only two things: the error that came back to this layer, and the activations that entered it.
  e(l) = (W(l+1))T e(l+1) ⊙ φ′(h(l))   and   ∂L/∂W(l) = e(l) (z(l−1))T 整个 demo 就围绕这两个式子。每一层的反向传播只需要两样东西：从上一层传回来的误差，和进入这一层的激活值。

keep it small — the point is that you can check every number by hand刻意保持很小——目的是每个数都能手算核对

2 inputs → 2 → 2 → 1 output with sigmoid → binary cross-entropy on one example. z(l) = φ(h(l)), p = z(L) = σ(h(L)), L = −[ y log p + (1−y) log(1−p) ]. Weights start on the grid {−0.5, −0.25, 0.25, 0.5} and every bias starts at 0, exactly as in a real network, so the first forward pass is exact mental arithmetic. 2 个输入 → 2 → 2 → 1 个 sigmoid 输出 → 单样本二元交叉熵。 z(l) = φ(h(l))，p = z(L) = σ(h(L))，L = −[ y log p + (1−y) log(1−p) ]。 权重取自网格 {−0.5, −0.25, 0.25, 0.5}，偏置全部从 0 开始（和真实网络一样），因此第一次前向可以完全心算。

D  Every node, in order逐个节点的账本

node节点 expression, with the numbers filled in表达式（数字已代入） value数值

Read it top to bottom: that is backprop. Every forward row is a line you could write down yourself; every backward row is the chain rule applied at one node, in reverse order. Notice that each layer's block looks exactly like the previous one — that is why the algorithm scales with depth. 从上往下读，这就是反向传播本身。前向每一行你都能自己写出来；反向每一行不过是把链式法则一个节点一个节点地倒着用。注意每一层的那一段和上一层长得完全一样——这正是它能随深度扩展的原因。

If you ever see a weight that did not move: check the activation it multiplies. ∂L/∂w = e·z, so if some z is exactly 0 the whole column of the gradient is 0 and those weights legitimately stay put — the arithmetic is right, there is simply nothing to learn from this example along that direction. The default draw avoids it: all four examples give every weight a non-zero gradient. Pressing ▶ next example keeps the updates (they accumulate), so the numbers you see are the result of every step taken so far. 如果看到某个权重没有变：先看它乘的那个激活值。∂L/∂w = e·z，所以如果某个 z 恰好是 0，这一列的梯度整列都是 0，那些权重就确实不动——算式没错，只是这个样本在这条方向上没有可学的东西。默认抽的权重避免了这种情况：四个样本都让每个权重有非零梯度。按 ▶ 下一个样本 时会保留之前的更新（它们是累加的），所以屏幕上的数字是到目前为止所有步的结果。

Everything runs in the browser: no server, no data leaves the page, and it works offline. Parameters are 64-bit floats, printed to four decimals, so the numbers on screen agree with a hand calculation. The gradient on each edge is ∂L/∂w for the single example currently shown — exactly what stochastic gradient descent uses. Notation follows the lecture: z = activation (forward), h = pre-activation, e = error signal (backward); the lecture writes the same identity as ∂L/∂Wl = el(zl−1)T, the rank-1 outer product of the error coming back and the activation going forward. 全部在浏览器里运行：没有服务器、数据不出页面、断网可用。参数是 64 位浮点，显示到四位小数，屏幕上的数和手算结果一致。每条边上的梯度就是当前这个样本的 ∂L/∂w——正是随机梯度下降实际使用的东西。记号与讲义一致：z = 激活（前向），h = 预激活，e = 误差信号（反向）；讲义把同一个恒等式写成 ∂L/∂Wl = el(zl−1)T，即「回传的误差」与「前传的激活」的秩 1 外积。
