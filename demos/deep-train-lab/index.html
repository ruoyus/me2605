The recipe that worked — pushed to a depth it has never seen 把那套「本来能用」的方案，推到它没见过的深度

Depth and width were both tuned before, but only over a limited range of each. Here the depth goes much further: pick L, watch the training loss, and see where a plain network stops learning. 之前深度 L 与宽度 d 都调过，只是各自的范围有限。这里把深度拉开：自己选 L，看训练 loss 的进展，看一个普通网络在哪里停止学习。

1 / 5

A fully connected network is a stack of affine maps and activations 全连接网络 = 一串仿射变换 + 激活函数

An L-layer fully connected network (FCN, a.k.a. MLP) in recursive form: 一个 L 层全连接网络（FCN，也叫 MLP）的递推写法：

z0 = x   ·   zl = φ(Wl zl−1 + bl)   ·   fθ(x) = WL zL−1 + bL
  • Wl has dl rows and dl−1 columns; d0 = dx, dL = dy. Wl 是 dl × dl−1 矩阵；d0 = dx，dL = dy。
  • This lab uses no bias, no normalization and no skip connections, so that what you see is the effect of depth and of the initialization scale alone. 本实验台不含偏置、不含归一化、不含跳跃连接，因此你看到的效果只来自深度与初始化尺度。
2 / 5

Two values per layer: pre-activation and post-activation 每一层有两个量：pre-activation 与 post-activation

pre-activation:  hl = Wl zl−1 + bl,   l = 1, …, L
post-activation:  zl = φ(hl),   l = 1, …, L−1 The last layer is taken without activation: fθ(x) = hL.

Both are tracked layer by layer, at the start of training and again at the end. Comparing the two curves is the point of the lab: it separates "the weights moved" from "a signal still reaches the top". 这两个量都会逐层跟踪，训练前记一次，训练后再记一次。比较这两条曲线正是本实验台的目的：它把「权重动了」与「信号还能传到顶层」区分开来。

3 / 5

Depth is a product of matrices, so any drift compounds 深度是一串矩阵相乘，任何偏差都会复利式放大

For a linear network zL = WL ⋯ W1 x. If each layer multiplies the norm by a factor c slightly off 1, the effect is exponential in L: 对线性网络，zL = WL ⋯ W1 x。只要每层把范数乘上一个略偏离 1 的因子 c，效果就随 L 呈指数级增长：

‖zL‖ ≈ ‖x‖ · cL c < 1 → vanishing  ·  c ≈ 1 → preserved  ·  c > 1 → exploding

The energy-preserving principle asks for the output energy to match the input: 能量守恒原则要求输出的能量与输入相当：

E‖ WL ⋯ W1 x ‖² / dL  =  ‖x‖² / d0

In expectation this holds at the classical gain. A single run is what you actually get, and a single run drifts — more so when the network is narrow, and more so the deeper you go. 在经典增益下它在期望意义下成立。但你真正拿到手的是一次具体的抽样，而这一次是会漂移的——网络越窄漂移越大，越深也越明显。

4 / 5

The initialization scale is the knob that sets c 初始化尺度就是控制 c 的那个旋钮

Wlij ~ N( 0 , g² / dl−1 ) g = 1 → Bottou–LeCun (var = 1/fan-in)  ·  g = √2 → He / Kaiming (for ReLU)

Both recipes are the same formula at a different gain, and both were checked on networks of moderate depth. This lab keeps the recipe and changes only the depth: the question is whether the same g still carries a signal through L layers. 两个方案是同一个公式、不同的增益，而且都是在中等深度的网络上验证过的。本实验台保留这套方案，只改深度：问题是同一个 g 是否还能把信号送过 L 层。

5 / 5

What the lab reports: the training loss, and the error 实验台报告什么：训练 loss 与 error

Training minimises a loss (binary cross-entropy); what you care about is the error, the fraction of misclassified examples. The lab plots both, because they fail in different ways. 训练最小化的是 loss（二元交叉熵），你真正关心的是 error——分错样本的比例。实验台两个都画，因为它们失效的方式不同。

A network whose signal has died outputs the same number for every input, so its loss sits at ln 2 ≈ 0.693 and its error at 50 % — the value of a coin flip. That pair is the fingerprint of "nothing is being learned", and it is easier to read off the loss curve than off the error alone. 信号已经死掉的网络对所有输入输出同一个数，于是它的 loss 停在 ln 2 ≈ 0.693、error 停在 50%——也就是抛硬币的水平。这一对数字就是「什么都没学到」的指纹，而且从 loss 曲线上比只看 error 更容易读出来。

Task: two interleaved moons, 2 features, 400 training and 400 test samples. 任务：两条交错的月牙，2 个特征，400 个训练样本、400 个测试样本。

What you can change — activation φ; the init gain g; the depth L (2 … 200); the width d (8 … 64); the seed. What is fixed — the two-moons task (400 train / 400 test, noise 0.13); mini-batch SGD, batch 32, learning rate 0.03, momentum 0.9; gradient clipping at norm 1; no bias, no normalization, no skip connections. The gain only enters through Wij ~ N(0, g²/fan-in). 能调的——激活函数 φ；初始化增益 g；深度 L（2…200）；宽度 d（8…64）；随机种子。固定的——双月牙任务（训练/测试各 400，噪声 0.13）；mini-batch SGD，批大小 32，学习率 0.03，动量 0.9；梯度按范数 1 裁剪；无偏置、无归一化、无跳跃连接。增益只通过 Wij ~ N(0, g²/fan-in) 起作用。

Two honest caveats. (1) Gradient clipping renormalises the update direction at every step, so a small gradient by itself does not stop the training here. (2) The activation decides what "dead" means. With ReLU, once the pre-activations sit at 0 the derivative is 0 as well, so a network that starts dead stays dead: at d = 24, g = √2, L = 200 the initial signal is about 6·10−6 of the input and training never leaves loss 0.693 / error 50 %. With tanh the derivative near 0 is close to 1, so the same initialization can revive during training: at d = 24, g = 1, L = 200 the initial signal is about 6·10−5 of the input, yet 400 steps still reach about 10 % test error. Depth is not the only variable here, and the lab lets you see that. 两点如实说明。（1）梯度裁剪每一步都会把更新方向重新归一化，所以在这里「梯度小」本身并不足以让训练停下来。（2）「死了」是什么意思由激活函数决定。对 ReLU，一旦 pre-activation 落在 0，导数也是 0，所以一开始就是死的网络会一直死下去：在 d = 24、g = √2、L = 200 时初始信号约为输入的 6·10−6，训练全程停在 loss 0.693 / error 50%。对 tanh，0 附近的导数接近 1，因此同样的初始化可以在训练中被救回来：在 d = 24、g = 1、L = 200 时初始信号约为输入的 6·10−5，但 400 步之后测试 error 仍达到约 10%。深度不是这里的唯一变量，实验台会让你看到这一点。
